# Library Management System

## Overview
A Python command-line Library Management System for managing books, members, book issue/return operations, and a library report.

## Features
- Add books
- View books
- Search books
- Add members
- View members
- Issue books
- Return books
- View library report
- Save data using JSON

## Technologies
- Python
- JSON

## How to Run
1. Install Python.
2. Open the project folder in a terminal.
3. Run:

```text
python main.py
```

## Data Storage
Library information is stored in `data/library.json`.
