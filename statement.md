# Project Statement

## Problem Statement
Managing books and members manually can make it difficult to keep track of available books and issued books.

## Scope
The system manages basic library operations such as adding books, adding members, searching books, issuing books, returning books, and viewing a library report.

## Target Users
- Small library staff
- Students learning Python
- Small personal libraries

## High-Level Features
- Book management
- Member management
- Issue and return management
- Library report
