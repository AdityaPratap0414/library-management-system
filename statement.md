## Problem Statement

Keeping library records on paper or in loose notes makes it hard to know which books are available and which books are issued. Searching for a book or checking a member takes time, and records can easily be written wrongly or lost.

This project provides a simple command-line program that stores book and member details and shows whether each book is available or issued.

## Scope of the Project

**Included:**
- Adding and viewing books
- Searching for a book by its ID
- Adding and viewing members
- Issuing and returning books
- Viewing a library report
- A numbered menu that runs in the terminal

**Not included:**
- Graphical interface
- User login
- Saving data to a file or database
- Online access

## Target Users

- Staff of a small library who need to manage books and members
- Students who want a simple example of a menu-driven Python program

## High-Level Features

| No. | Feature | Description |
|-----|---------|-------------|
| 1 | Add Books | Saves a new book as available |
| 2 | View Books | Shows all books and whether each is available |
| 3 | Search Book | Finds a book by its Book ID |
| 4 | Add Members | Saves a new member |
| 5 | View Members | Shows all members |
| 6 | Issue Book | Marks a book as issued |
| 7 | Return Book | Marks an issued book as available again |
| 8 | Library Report | Shows total, available and issued books and total members |
| 9 | Exit | Ends the program |
